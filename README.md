# Healthcare Stroke Data Analysis

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a healthcare stroke dataset to identify patterns and relationships between patient characteristics and stroke occurrence.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Tasks
- Data Cleaning
- Missing Value Analysis
- Statistical Analysis
- Correlation Analysis
- Data Visualization

## Visualizations
- BMI Distribution
- Gender Distribution
- BMI vs Average Glucose Level
- BMI by Smoking Status
- Average Glucose Level by Age

## Conclusion
The project explores relationships between age, BMI, glucose levels, smoking status, and stroke occurrence using data analysis and visualization techniques.
